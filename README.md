  Quiz Divertido: Conhecendo Brusque

Um jogo educativo desenvolvido para crianças pequenas, com o objetivo de ensinar sobre a cultura, história e curiosidades da cidade de Brusque de forma lúdica e acessível.
----------------

  **Objetivo do Projeto**
  
Este projeto foi criado pensando na acessibilidade para o público infantil. O design é vibrante, com botões grandes e um sistema de feedback cauteloso. Se a criança errar, ela é incentivada a tentar novamente de forma gentil, garantindo uma experiência de aprendizado positiva.

  **Tecnologias Utilizadas**
Para manter o projeto simples e educativo, utilizamos apenas:
- **HTML5**: Estrutura das questões e navegação.
- **CSS3**: Estilização visual e lógica de transição de telas.
